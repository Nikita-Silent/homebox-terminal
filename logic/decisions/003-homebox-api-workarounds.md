# 003. Обход особенностей Homebox API

**Дата:** 2026-10-14 · **Статус:** принято

## Контекст

Проверено на Homebox 0.26.2 (подробно: `docs/homebox-api-notes.md`):

- `PUT /entities/{id}` заменяет запись целиком и обнуляет непереданные поля (в том числе UID).
- Поиск `q` не находит кириллицу.
- Сервер принимает отрицательное и дробное количество.

## Решение

- Все изменения — через `PATCH` (меняет только переданные поля). `PUT` используется в одном месте —
  снять метку с имени новой копии — и получает полный набор полей из свежего `GET`.
- Поиск по названию и UID идёт по локальной копии списка вещей (обновляется раз в 30 секунд);
  поиск Homebox используется для модели и серийного номера.
- Количество проверяется сервером терминала: целое, не меньше 1, не больше остатка.

## Последствия

- При обновлении Homebox эти особенности нужно перепроверить: исправленный поиск позволит убрать
  локальную копию, появление частичного обновления — убрать `PUT`.
