# 002. Когда объединять записи

**Дата:** 2026-10-14 · **Статус:** принято

## Контекст

На складе ~800 записей, отдельной разметки «расходник / поштучное» нет. Поштучное оборудование
(где важна история) уже заведено записями по 1 шт. Для расходников важна сумма, а не отдельные штуки.

## Решение

- Количество определяет тип учёта: 1 шт. — поштучный, больше 1 — количественный.
- Объединяются только количественные записи одного товара на одной полке, и источник, и цель > 1 шт.
- Перенос части количества: добавить к такой же записи на полке; если её нет — создать копию.
- Перенос всего количества: добавить к такой же записи и удалить опустевшую исходную запись.
- «Такой же товар»: производитель + модель; без модели — точное название.
- Несколько подходящих записей — выбирает сотрудник. Всегда доступно «Записать отдельной строкой».

## Последствия

- Расходник, у которого осталась ровно 1 шт., считается поштучным: перенос к нему создаст вторую
  строку. Это безопасная ошибка (данные не смешиваются), строки можно объединить вручную.
- При объединении всего количества история исходной записи (фото, заметки) удаляется вместе с ней.
